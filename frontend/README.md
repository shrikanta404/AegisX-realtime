# AegisX Frontend

React + TypeScript + Vite interface for the AegisX backend.

## Run

```powershell
npm install
npm run dev
```

Set `VITE_API_BASE_URL` when the backend is not at `http://localhost:8000/api/v1`.

## Pages

- Command Center: live API-backed dashboard
- Attack Surface: 3D inventory graph
- Assets: current asset inventory
- Changes: change timeline
- Findings: evidence, false-positive review and AI analysis
- Reports: reporting window, summary and export
- Settings: authorized scopes, scheduler and audit log
