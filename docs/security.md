# AegisX Security Controls

- Authorized domain matching with parent-domain support.
- Active-scope enforcement on inventory and monitoring endpoints.
- Configurable port/check set per scope.
- Host/domain limits aligned with the challenge's prototype scale.
- Evidence retained with findings.
- False-positive reason required.
- Audit logging for scope, monitoring and review events.
- AI prompts explicitly forbid invented CVEs, exploit claims and target expansion.
